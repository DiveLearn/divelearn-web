🌐 2.1 El Sistema de Direcciones Universal

¿Por qué necesitamos direcciones numéricas?

Imagina Internet como una ciudad gigantesca con millones de edificios (dispositivos). Para que los mensajes lleguen a su destino, cada edificio necesita una dirección única. Las direcciones IP son como códigos postales súper precisos que permiten que los datos viajen exactamente donde deben ir.
🏠 Analogía del mundo real:
Tu casa: "Calle Principal 123, Ciudad, País"
Tu computadora: "192.168.1.100" (en tu red local)

IPv4: El sistema actual (como códigos postales)

IPv4 usa direcciones de 32 bits escritas como cuatro números del 0 al 255, separados por puntos. Ejemplo: 192.168.1.1. Este sistema puede crear aproximadamente 4.3 mil millones de direcciones únicas.
🔢 Ejemplos de IPv4:
• 8.8.8.8 - DNS de Google
• 192.168.1.1 - Router doméstico típico
• 127.0.0.1 - Tu propia computadora (localhost)

IPv6: El futuro (coordenadas GPS súper precisas)

IPv6 usa direcciones de 128 bits escritas en hexadecimal. Permite 340 sextillones de direcciones (suficientes para dar una dirección a cada átomo visible del universo). Ejemplo: 2001:0db8:85a3:0000:0000:8a2e:0370:7334

🏢 2.2 Direcciones Públicas vs Privadas

Direcciones públicas: Tu casa en la calle principal

Las direcciones públicas son únicas en todo Internet. Son como direcciones de casas en calles principales que cualquier servicio de delivery puede encontrar directamente.

Direcciones privadas: Apartamentos dentro de un edificio

Las direcciones privadas solo funcionan dentro de tu red local. Son como números de apartamento - el apartamento 3B solo tiene sentido si sabes en qué edificio está.
🏠 Rangos de direcciones privadas:
• 10.0.0.0 - 10.255.255.255 (Clase A)
• 172.16.0.0 - 172.31.255.255 (Clase B)
• 192.168.0.0 - 192.168.255.255 (Clase C)

Traducción: Cómo los privados se conectan al mundo

El NAT (Network Address Translation) actúa como un traductor que convierte direcciones privadas en públicas cuando salen a Internet. Es como tener un recepcionista que recibe toda la correspondencia del edificio y la distribuye a los apartamentos correctos.

🎭 2.3 Máscaras y Rangos

Máscaras de red: Definir el vecindario

Las máscaras de subred definen qué parte de una dirección IP identifica la red y qué parte identifica el dispositivo específico. Es como definir los límites de un barrio.
🎭 Máscaras comunes:
• 255.255.255.0 (/24) - 254 dispositivos
• 255.255.0.0 (/16) - 65,534 dispositivos
• 255.0.0.0 (/8) - 16,777,214 dispositivos

Notación CIDR: La forma corta de escribir rangos

CIDR (Classless Inter-Domain Routing) es una forma compacta de escribir máscaras. En lugar de escribir 255.255.255.0, simplemente escribes /24 (porque los primeros 24 bits definen la red).

📐 2.4 Planificación de Direcciones

Dividir una red grande en pedazos pequeños (subneteo)

El subneteo es como dividir un edificio grande en apartamentos más pequeños. Tomas una red grande y la divides en subredes más manejables para diferentes departamentos o propósitos.

Reservar espacio para crecimiento

Siempre planifica con espacio extra. Si hoy necesitas 50 direcciones, reserva espacio para 100 o 200. Es como comprar una casa más grande de lo que necesitas ahora, pensando en el futuro.

🧮 2.5 Práctica de Subneteo

Método visual para dividir redes

Usa el método de potencias de 2: para saber cuántas subredes puedes crear, pregúntate "¿cuántos bits puedo tomar prestados?". Cada bit prestado duplica el número de subredes posibles.
🧮 Ejemplo práctico:
Red original: 192.168.1.0/24
Divides en 4 subredes: /26 (tomas prestados 2 bits)
Resultado: 4 subredes de 62 hosts cada una
