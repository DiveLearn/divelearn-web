💡 Tips de Configuración DNS

🌐 Registro A: Apunta tu dominio a una dirección IPv4. Usa "@" para el dominio raíz o "www" para el subdominio web.
📧 Registro MX: Configura dónde llega tu correo. Menor prioridad = mayor importancia (10 antes que 20).
🔗 Registro CNAME: Crea alias para subdominios. No puede coexistir con otros registros en el mismo nombre.
📝 Registro TXT: Usado para verificaciones (SPF, DKIM), Google Site Verification, y otras validaciones.
⚡ TTL Bajo: Para entornos de desarrollo o cuando esperas cambios frecuentes (300-900s).
🏗️ TTL Alto: Para producción estable, reduce la carga en servidores DNS (3600-86400s).
