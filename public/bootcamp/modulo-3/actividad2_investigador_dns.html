Usa herramientas de consulta DNS para investigar dominios reales

Objetivo

En esta actividad usarás herramientas de consulta DNS simuladas para investigar diferentes tipos de registros DNS de dominios reales. Aprenderás a interpretar respuestas DNS y entender cómo funciona la resolución de nombres en la práctica.

Progreso de Investigación
Consultar registro A (dirección IPv4)
Consultar registro MX (servidor de correo)
Consultar registro CNAME (alias)
Consultar registro TXT (información adicional)
Consultar registro NS (servidores de nombres)

Tips de Investigación DNS

Registro A: Muestra la dirección IPv4 donde está alojado el dominio. Un dominio puede tener múltiples registros A para balanceo de carga.
Registro MX: Indica qué servidores manejan el correo electrónico. El número es la prioridad (menor = mayor prioridad).
Registro CNAME: Crea un alias. No puede coexistir con otros registros en el mismo nombre.
Registro TXT: Almacena texto arbitrario, usado para verificaciones SPF, DKIM, y políticas de seguridad.
TTL: Time To Live - cuánto tiempo puede ser cacheada la respuesta (en segundos).
