Tips para Diseñar Bases de Datos

Clave primaria: Cada tabla debe tener un campo único que identifique cada registro (como ID).
Tipos de datos: Elige el tipo correcto: números para cálculos, texto para nombres, fechas para eventos.
Relaciones: Conecta tablas usando campos en común (como id_empleado en tabla de ventas).
Nombres claros: Usa nombres descriptivos: "fecha_nacimiento" en lugar de "fn".
