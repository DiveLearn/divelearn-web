Editor de Archivos de Configuración

Edita archivos de configuración importantes usando editores de texto

20 minutos
Nivel: Básico-Intermedio
Puntos: 175

Objetivo

En esta actividad aprenderás a editar archivos de configuración importantes en Linux. Trabajarás con archivos como .bashrc, /etc/hosts, variables de entorno y configuraciones de servicios, usando editores de texto simulados.

~/.bashrc

Sobre ~/.bashrc
El archivo .bashrc se ejecuta cada vez que abres una nueva terminal. Aquí puedes configurar aliases, variables de entorno, funciones personalizadas y la apariencia de tu prompt. Es tu espacio personal para personalizar la experiencia de la terminal.
Tips de Configuración
Recargar configuración: Usa source ~/.bashrc para aplicar cambios sin reiniciar la terminal.
Backups: Siempre haz backup de archivos de configuración antes de editarlos: cp archivo archivo.backup
Permisos: Algunos archivos de configuración requieren permisos específicos para funcionar correctamente.
Comentarios: Usa # para comentar líneas y documentar tus configuraciones.

Desafíos de Configuración

Desafío 1: Agrega un alias para mostrar el espacio en disco disponible (df -h).
Desafío 2: Configura una entrada en /etc/hosts para mapear "miservidor.local" a 127.0.0.1.
Desafío 3: Añade una variable de entorno personalizada en el archivo .env.
Desafío 4: Modifica la configuración de Nginx para servir archivos desde un directorio diferente.
