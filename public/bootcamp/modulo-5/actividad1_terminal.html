🖥️ Terminal Interactiva

Practica comandos básicos de Linux en un simulador de terminal

⏱️ 25 minutos
🎯 Nivel: Básico
🏆 Puntos: 150

🎯 Objetivo

En esta actividad aprenderás y practicarás los comandos básicos de Linux usando un simulador de terminal interactivo. Dominarás la navegación, gestión de archivos y comandos esenciales para el trabajo diario con servidores.

💻 Terminal Simulada

Terminal - Linux Simulator
Bienvenido al simulador de terminal de Linux! Escribe 'help' para ver los comandos disponibles. usuario@linux:~$
usuario@linux:~$

📚 Comandos Disponibles

Haz clic en cualquier comando para probarlo:

pwd
Mostrar directorio actual
ls
Listar archivos y carpetas
ls -la
Listar con detalles
cd documentos
Cambiar directorio
mkdir nueva_carpeta
Crear directorio
touch archivo.txt
Crear archivo
cat archivo.txt
Ver contenido
whoami
Usuario actual
date
Fecha y hora
clear
Limpiar terminal

🎯 Desafíos Prácticos

Desafío 1: Navega al directorio "documentos" y lista su contenido con detalles.
Desafío 2: Crea una carpeta llamada "mi_proyecto" y dentro de ella crea un archivo "readme.txt".
Desafío 3: Usa el comando "find" para buscar todos los archivos .txt en el sistema.
Desafío 4: Combina comandos usando pipes (|) para filtrar resultados.

💡 Tips y Trucos

🎯 Autocompletar: En Linux real, usa la tecla TAB para autocompletar nombres de archivos y comandos.
🔍 Historial: Usa las flechas ↑ y ↓ para navegar por comandos anteriores.
🚀 Combinaciones: Puedes combinar comandos con && (si el anterior es exitoso) o || (si el anterior falla).
📁 Rutas: Usa ~ para referirte a tu directorio home, y .. para subir un nivel.
