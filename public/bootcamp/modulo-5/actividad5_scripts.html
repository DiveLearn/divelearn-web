Creador de Scripts Básicos

Crea tus primeros scripts de automatización en Bash

35 minutos
Nivel: Intermedio
Puntos: 250

Objetivo

En esta actividad aprenderás a crear scripts básicos en Bash para automatizar tareas repetitivas. Dominarás conceptos como variables, condicionales, bucles y programación de tareas con Cron.

Ejemplos de Scripts Útiles

Verificar Espacio en Disco
df -h | grep -E "(Filesystem|/dev/)" | head -5
Monitorea el espacio disponible en disco
Monitor de Procesos
ps aux | sort -nrk 3,3 | head -5
Muestra los procesos que más CPU consumen
Rotación de Logs
find /var/log -name "*.log" -mtime +7 -exec gzip {} \;
Comprime logs antiguos para ahorrar espacio
Escaneo de Seguridad
last | head -10; who; w
Revisa últimos accesos y usuarios conectados

Desafíos de Scripting

Desafío 1: Modifica el script básico para que salude con tu nombre real.
Desafío 2: Crea un script de backup que copie una carpeta con la fecha actual.
Desafío 3: Programa una tarea con Cron para ejecutar cada lunes a las 9:00 AM.
Desafío 4: Añade validación de argumentos a tu script (verificar que se pasaron parámetros).

Mejores Prácticas de Scripting

Shebang: Siempre inicia con #!/bin/bash para especificar el intérprete.
Comentarios: Documenta tu código con comentarios claros y útiles.
Validación: Verifica que los archivos existen y los comandos son exitosos.
Permisos: Usa chmod +x para hacer ejecutable tu script.
Logging: Registra la ejecución y errores en archivos de log.
