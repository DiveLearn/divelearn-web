¿Cuál es el comando correcto para listar archivos con detalles incluyendo permisos y fechas?

A) ls
Lista archivos básicos sin detalles
B) ls -la
Lista todos los archivos con formato largo
C) dir
Comando de Windows, no disponible por defecto en Linux
D) list -all
No es un comando válido en Linux

¿Qué significan los permisos 755 en un archivo o directorio?

A) rwxr-xr-x
Propietario: lectura, escritura, ejecución. Grupo y otros: lectura y ejecución
B) rw-r--r--
Propietario: lectura y escritura. Grupo y otros: solo lectura
C) rwxrwxrwx
Todos los permisos para todos los usuarios
D) r--r--r--
Solo permisos de lectura para todos

¿Cuál es la función principal del archivo ~/.bashrc?

A) Configurar el escritorio gráfico
El bashrc no controla la interfaz gráfica
B) Personalizar el entorno de la terminal
Define aliases, variables de entorno y configuraciones del shell
C) Gestionar contraseñas de usuario
Las contraseñas se manejan en otros archivos del sistema
D) Configurar la red del sistema
La configuración de red tiene sus propios archivos

¿Qué comando usarías para conectarte a un servidor remoto usando SSH?

A) connect usuario@servidor.com
No es un comando válido de SSH
B) ssh usuario@servidor.com
Sintaxis correcta para conexión SSH
C) telnet usuario@servidor.com
Telnet no es seguro y generalmente está deshabilitado
D) ftp usuario@servidor.com
FTP es para transferencia de archivos, no para shell remoto

¿Qué significa la siguiente expresión de Cron: 0 2 * * 1?

A) Ejecutar cada 2 minutos todos los días
Esta interpretación es incorrecta de la sintaxis cron
B) Ejecutar todos los lunes a las 2:00 AM
0=minuto, 2=hora, *=cualquier día del mes, *=cualquier mes, 1=lunes
C) Ejecutar el día 1 de cada mes a las 0:02
El orden de los campos no corresponde a esta interpretación
D) Ejecutar cada hora desde las 2:00 hasta las 23:00
Esta sintaxis no representa un rango horario
