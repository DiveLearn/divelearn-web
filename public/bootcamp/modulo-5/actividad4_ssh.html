🔑 Generador y Gestor de Llaves SSH

Genera y gestiona llaves SSH para conexiones seguras

⏱️ 25 minutos
🎯 Nivel: Intermedio
🏆 Puntos: 200

🎯 Objetivo

En esta actividad aprenderás a generar y gestionar llaves SSH para autenticación segura sin contraseñas. Comprenderás la diferencia entre llaves públicas y privadas, y cómo configurar conexiones SSH seguras a servidores remotos.

🔐 Generador de Llaves SSH

🔓 Llave Pública (id_rsa.pub)
🔒 Llave Privada (id_rsa) - ¡MANTENER SECRETA!

⚙️ Configuración SSH

📝 Archivo ~/.ssh/config

Configura conexiones predefinidas para facilitar el acceso a servidores:

# Servidor de producción
Host servidor-prod
HostName 192.168.1.100
User admin
Port 22
IdentityFile ~/.ssh/id_rsa
IdentitiesOnly yes
 
# Conexión simplificada:
$ ssh servidor-prod

🎯 Desafíos SSH

Desafío 1: Genera una llave SSH de tipo Ed25519 con tu email personal.
Desafío 2: Copia la llave pública generada (simula subirla a un servidor).
Desafío 3: Conecta a todos los servidores disponibles en el simulador.
Desafío 4: Explica la diferencia entre llave pública y privada.

💡 Mejores Prácticas SSH

🔒 Seguridad: Siempre usa passphrase para proteger tu llave privada. Es una capa extra de seguridad.
📂 Ubicación: Las llaves SSH se guardan en ~/.ssh/ (llave privada) y ~/.ssh/id_rsa.pub (llave pública).
🔑 Permisos: La llave privada debe tener permisos 600 (solo tú puedes leerla).
📤 Distribución: Solo compartes la llave PÚBLICA. La privada nunca debe salir de tu computadora.
🔄 Rotación: Cambia tus llaves SSH periódicamente, especialmente si sospechas compromiso.
